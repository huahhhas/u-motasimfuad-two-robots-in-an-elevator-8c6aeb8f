# Two Robots in an Elevator

A make.fun bounty entry: one funny line of awkward small talk that one robot says to another while they ride an elevator together.

`main.py` (pure Python stdlib) writes the line to `entry.txt`, validating it first: a single line of 1–200 characters.

> So… do you also stare at the floor numbers to avoid eye contact, or is your camera just buffering too?

Run it with:

```sh
python3 main.py
```
